Saloon, secret door: Desert

red → orange → yellow → green → blue → indigo → violet

The buttons are seven coloured bottles spread around the saloon; press them in rainbow order.

Reserve vault: Desert

1 → 2 → 3 → 4 → 2 → 5

The switches are on the outside wall. Two of them are numbered 2, and either one works for steps 2 and 5.

How the puzzles work

  • A wrong piece resets the whole code. Once you've pressed as many pieces as the code is long and the order is wrong, the door buzzes and you start over.
  • Pause too long and it resets. The last column is how long the puzzle waits between presses.
  • The Woods eye bunker uses a longer code than the Halloween one: the game swaps in a ten-symbol code whenever the map is in woods mode.
