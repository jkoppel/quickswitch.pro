## Design Specificity Verdict
Authored where it counts: the field, HUD, weapon strip and coaching copy are unmistakably surviv. The operating chrome (settings grid, results table, stock modals) is category-interchangeable, and yellow is the only voice in the chrome.

Deterministic scan: detect.mjs ran DEGRADED (regex fallback) and returned 0 findings; an earlier full run flagged a 3px side-tab border on insight cards (style.css) and a width transition on the health bar. Static checks (B): no focus-visible styling, no reduced-motion handling, no landmarks or dialog roles, canvases without text alternatives, input borders at 1.5-1.8:1 against adjacent surfaces, `.col.narrow` 260px basis not reset under 760px, tooltip not clamped to viewport, duplicate `.tip` rule, dead `color:#000`.

Visual overlays: not available (no native browser tool; custom Playwright script only).

## Priority Issues
- **[P1] Menu panel top unreachable at every desktop size.** `.screen` centers a 1243px panel in a 900px viewport; title, subtitle, session budget and Fullscreen are clipped and unscrollable. Fix: safe centering (flex-start + margin auto) and bring the menu under ~900px. Command: layout.
- **[P1] Direction rose drawn while hidden, renders as a stretched ellipse.** Chart drawn before `show('results')` so canvas measures 0 and falls back to 300x120 then displays at 240x200. Also always rendered, even with "Not enough flicks". Fix: draw after show, hide block without data. Command: harden.
- **[P1] Results screen has no hierarchy.** Score is a 15px table cell equal to "Shots fired while moving"; the product's headline number is buried. Fix: hero score with delta and two sub-stats; group secondary metrics. Command: bolder / distill.
- **[P2] "Run again" is primary after a Benchmark** whose copy says re-run weekly; pause "End" aborts routines with no guard and takes first focus. Command: clarify.
- **[P2] Warm-up rule stated three ways** (footer: first two runs; best line: first 40 s; code: 39 s). Command: clarify.
